# Adventure

A personal, phone-first web app that puts outdoor conditions, a 3D map and our adventure hit list together,
so it can say things like "you planned a hike, but the surf down south is perfect and there's a free campsite nearby."

- **What we're building:** [docs/BRIEF.md](docs/BRIEF.md)
- **Current plan:** [docs/PLAN.md](docs/PLAN.md)
- **Who's working where:** [ZONES.md](ZONES.md)
- **First-time setup (Supabase, Pages):** [SETUP.md](SETUP.md)
- **Instructions for Claude:** [CLAUDE.md](CLAUDE.md)

Live site: https://samclagett.github.io/adventure/

## Running locally

```bash
npm install
cp .env.example .env.local   # then fill in the Supabase values
npm run dev
```
